# Certificates Directory

Place your certificate images inside this folder so they appear on your portfolio website!

## Instructions:
1. Copy your certificate images into this folder (`c:\Users\Cristiano\Desktop\portfolio\certificates\`).
2. Name them accordingly:
   - `cert1.jpg` (Full Stack Web Development Certificate)
   - `cert2.jpg` (React & Frontend Architecture Certificate)
   - `cert3.jpg` (Node.js & Backend Systems Certificate)
   - Additional certificates: `cert4.jpg`, `cert5.jpg`, etc.
3. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.

When someone clicks "View Certificate 📜" on the website, it will open the certificate image in a modal lightbox viewer!
